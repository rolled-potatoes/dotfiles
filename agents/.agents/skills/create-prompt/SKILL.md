# 프롬프트 생성하기 
AGENT 를 통해서 사용자가 가장 기대하는 결과물을 작성하기 위해서는 좋은 명령과 정보 그리고 지침이 내려져야한다. 이를 위한 프롬프트를 구성한다. 

## 작업 수행 

### 1. 환경 주입 

현재 작업하는 환경을 이해하며, 입력된 내용을 이해하며 양질의 질문을 할 수 있도록 프로젝트 조사를 러프하게 수행한다. (본 작업 세션에서 조사해야하므로 토큰 낭비로 이어질 수 있음)

### 2. 입력에 따른 질의하기. 

입력된 작업을 위해서 프롬프트를 잘 작성하고자할때, 어떤 요소를 고려해야할지, 어떤 지침이 추가로 주어져야하는지 나한테 질문을 한다. 

### 3. 프롬프트로 정리하기. 

입력된 내용과 정리된 질문의 내용, 지침을 정리하여 4000자 내로 목표 프롬프트를 작성한다. 

## 작업 규칙 

- 스킬을 통해서 입력된 내용이 없다면 스킬은 종료한다. 
- 질문은 답변을 맵핑할 수 있도록 순서 번호를 매겨서 제시한다. 
- 질문에 답변이 없는 문항은 AGENT 자체 판단으로 한다. 
- `입력 -> 질문 -> 생성` 로 단순하게 한번의 작업으로 끝내지 않는다. 다른 agent or session에서 작업에 충분한 정보가 모여있지 않으면 집요하게 질문을 수행한다. 
    - 그렇다고 한번으로 충분했는데, 굳이 여러번 루프를 수행할 필욯난 없다. 
- 본 스킬은 작업을 위한 "프롬프트 생성"로 제한하며, 본 작업은 다른 agent or session 에서 수행한다.
