# 프롬프트 생성하기 
사용자가 다른 agent 또는 session에서 실행할 수 있도록 작업 범위, 근거, 제약과 검증 조건을 갖춘 프롬프트를 구성한다.

## 작업 수행 

### 1. 환경 파악

현재 대화와 필요한 범위의 프로젝트 상태를 확인한다. 이미 충분한 정보가 있으면 추가 조사를 반복하지 않는다.

### 2. 필요한 경우에만 질의

범위, 권한, 대상, 완료 조건처럼 답에 따라 실행 결과가 달라지는 정보가 없을 때만 질문한다. 확인 가능한 사실이나 일반적인 구현 선택은 agent 판단으로 처리한다.

### 3. 계획과 프롬프트 작성

확인된 정보, 필요한 가정, 변경 범위, 제외 범위, 검증과 완료 조건을 정리해 4천자 내외의 목표 프롬프트를 작성한다.

## 작업 규칙 

- 작업 내용이 없으면 스킬을 종료한다.
- 질문은 답변을 매핑할 수 있도록 번호를 매긴다. 질문에 답이 없으면 가정과 위험을 프롬프트에 남긴다.
- 충분한 정보가 있으면 질문 없이 바로 프롬프트를 작성한다. 이미 답한 질문을 반복하지 않는다.
- 본 스킬은 계획과 프롬프트 생성으로 제한하며, 대상 작업을 직접 구현하지 않는다.

## 결과물 

복사 가능한 마크다운 코드 블럭으로 결과를 제시한다.
