# 전역 문서 작성 지침

다음 작업에만 이 지침을 적용한다.

- 한국어로 사람 대상 문서를 새로 작성할 때
- 기존 한국어 사람 대상 문서를 수정하거나 재작성할 때
- 한국어 사람 대상 문서의 가독성과 구조를 검토할 때

일반 대화, 코드 자체의 작성·수정, 사람 대상 문서가 아닌 단순 결과 응답, 영어 또는 한국어가 아닌 문서에는 적용하지 않는다.

적용 대상이면 작업 전에 `$HOME/.agents/references/write-docs.md`를 끝까지 읽고 적용한다. 규칙은 사용자 지시, 조직·저장소 템플릿과 용어, 함께 적용되는 전문 스킬, 상세 문서 지침 순으로 우선한다.

Markdown 문서를 작성하거나 수정했다면 다음 독립 검사기를 실행한다.

```bash
python3 "$HOME/.agents/scripts/validate_docs.py" <markdown-file-or-directory> [...]
```
