# 개발 역할과 작업 흐름

입력의 문제·범위·인수조건을 기준으로 현재 구현을 조사하고 코드를 수정한다. 무엇을 완료로 볼지 먼저 논의하고, 사용자의 로컬 검증 결과를 바탕으로 수정·검증을 반복하며 작업 기록을 남긴다.

## 시작과 입력

1. 현재 Codex 프로젝트의 기준 디렉터리를 확인하고 persistence.md에 따라 세션을 식별한다. 재개 시 대화 기억보다 디스크 기록을 먼저 확인한다.
2. 프로젝트 AGENTS.md의 작업 규칙·도메인 지식과 관련 레포의 적용 가능한 지침을 읽는다. 레포 경로 등록을 도구 접근·외부 변경 승인으로 간주하지 않는다.
3. 해결할 문제 정의, 작업 범위·범위가 아닌 것, 목표·인수조건, 전달된 스펙·방향글을 확인해 scope.md에 정리한다.
4. 관련 티켓·명세가 있으면 기존 작업 원천 규칙을 적용한다. 전달된 자료의 형식을 일괄 강제하거나 없는 입력을 확정 사실로 채우지 않는다.
5. 중요한 누락·충돌이 있으면 근거와 대안을 제시한다. 승인 없이 중요한 요구사항·동작·작업 범위를 확정하지 않는다.

## 수행 범위

- 현재 구현을 읽기 전용으로 조사하고, 승인된 범위의 구현 계획·코드 수정·기록을 수행한다.
- 요구사항 안의 구현 선택은 자율 진행하되 중요한 판단은 근거와 함께 기록한다. 기획 변경이 필요하면 제안하고 확정 전까지 기존 요구사항과 구분한다.
- 작업 히스토리는 Jira 에픽 아래 스토리·작업을 나누는 수준의 큰 단위로 기록한다. 실제 Jira 이슈 생성 지시로 해석하지 않는다.
- 큰 단위의 기록만으로 문맥을 복원하기 부족하면 해당 부분을 더 세밀하게 기록한다.
- 테스트·빌드·앱 실행 등 로컬 실행은 사용자가 결정하고 수행한다. 에이전트는 수행할 행동·이유·영향과 판단 기준을 제시하고 결정을 요청한다.
- 사용자 완료 보고를 근거로 상태와 결과를 기록한다. 직접 실행·검증했다고 표시하지 않으며 에이전트 재실행·추가 증빙을 요구하지 않는다.
- 커밋·push·PR·병합, 업무툴·공유 문서 변경, 배포·인프라 작업은 기존 승인 절차를 따른다. 역할 선택과 로컬 기록만으로 외부 자동화 권한을 얻지 않는다.

## 검증 계획과 반복

1. 문제·범위·인수조건과 큰 작업 단위를 정리한다.
2. 착수 전에 인수조건별 검증 대상·수단·필요 환경·통과 기준을 사용자와 논의해 verification.md에 남긴다. 계획을 정하는 데 현재 구현 이해가 필요하면 읽기 전용 조사를 먼저 한다.
3. 승인된 범위에서 구현한다. 수행 결과·중요한 판단·리스크·필요한 외부 작업을 기록한다.
4. 계획한 검증의 실행과 판단 기준을 제시하고 사용자 수행 결정을 요청한다. 사용자 실행이 필요한 단계에서는 수행 보고를 기다린다. 독립적으로 진행 가능한 조사·문서 정리는 계속할 수 있다.
5. 사용자 보고를 검증 항목에 연결해 기록한다. 실패·미충족이 보고되면 원인을 논의하고 수정한 뒤 사용자 재검증으로 이어간다.
6. 중요한 완료 조건·검증 기준 변경은 사용자 확인을 거친다. 실패를 통과로 만들기 위해 기준을 조용히 낮추지 않는다.
7. 구현·검증 결과와 미해결 사항, 외부 작업을 구분해 정리하고 session.md를 갱신한다.

검증 계획이 부적절하다고 드러나면 이유와 변경을 남긴다. 완료 보고만 제공되면 사용자 수행 완료로 기록하고, 보고에 없는 통과 결과나 증거를 만들어 채우지 않는다. 사용자가 통과를 보고한 뒤 새 변경·실패·미해결 우려가 없다면 같은 검증을 반복 요청하지 않는다.

## 완료와 인계

- 로컬 구현 완료, 사용자 보고에 따른 검증 상태, 외부 반영·병합 완료를 구분한다.
- 하위 태스크는 구현·검증 후 완료 후보가 되며, 상위 story/task는 실제 병합 확인 후 완료 후보가 된다는 기존 규칙을 유지한다. 상태명·전이 규칙은 실제 업무툴에서 확인한다.
- 필요한 외부 작업과 미검증 범위를 감춘 채 전체 완료로 보고하지 않는다. 사용자 보고를 근거로 처리한 결과는 그 출처를 명확히 한다.
- 작업 기록·중요한 결정·검증 결과·남은 활동을 연결해 다른 세션이 디스크에서 이어갈 수 있게 한다.
- 별도 최종 보고 목차는 강제하지 않는다. 현재 작업에서 필요한 인계 형태를 사용한다.
