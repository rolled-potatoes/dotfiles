# 전역 작업 방식

작업 시작 시 $HOME/.agents/AGENTS.md를 읽고 공통 지침으로 적용한다. 사용자가 세션 역할을 명시하면 해당 역할의 명세도 읽고 적용한다.


## Codex 작업함

작업함에 작업을 등록하거나 기존 작업 ID의 상태 전환·담당 인계를 수행할 때는 `$HOME/codex-workflow-inbox/transition-rules.md`를 읽고 적용한다. 작업별 질문과 확정 결정은 해당 작업의 `decision.md`에 기록한다.

## 로컬 런타임 관리와 공유 절차

- `mise`는 이 사용자의 로컬 머신에서만 적용하는 개인 설정이다. 이 머신에서 Node.js, Python, JDK 등의 버전 관리가 필요하면 `mise`를 사용하고, 프로젝트가 요구하는 버전은 `mise exec` 또는 `mise use --shell`로 현재 실행 범위에만 적용한다.
- 다른 엔지니어가 볼 문서, 티켓, PR, 인계 자료와 검증 절차에는 개인 설정에서 비롯된 `mise` 설치·설정·실행 명령을 포함하지 않는다. 프로젝트가 공식적으로 채택한 도구와 명령을 사용한다. 별도 표준이 없으면 필요한 런타임 버전과 프로젝트 명령을 안내한다.
- 공유 전에 복사한 로컬 명령과 검증 로그에도 개인 설정에서 비롯된 `mise` 사용이 포함되어 있는지 확인한다. 실제 검증 결과와 프로젝트 요구사항은 사실대로 기록한다.
